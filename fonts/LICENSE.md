# Bundled fonts

Both fonts are the Latin subset of the variable fonts served by Google Fonts (downloaded 14 October 2026). They are bundled so the extension page makes no requests to third parties.

| File | Font | Copyright | Source |
|---|---|---|---|
| `BricolageGrotesque.woff2` | Bricolage Grotesque (opsz 12–96, wght 200–800) | Copyright 2022 The Bricolage Grotesque Project Authors | https://github.com/ateliertriay/bricolage |
| `DMSans.woff2` | DM Sans (opsz 9–40, wght 100–1000) | Copyright 2014 The DM Sans Project Authors | https://github.com/googlefonts/dm-fonts |

Both are licensed under the SIL Open Font License, Version 1.1: https://openfontlicense.org/open-font-license-official-text/

The license allows bundling and redistributing the fonts with software, but not selling them on their own. If the extension is published, include the full OFL text with the fonts.
